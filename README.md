
# Wellness Studio

Sitio web de un estudio de Pilates y Barre, donde se muestran las clases, los paquetes disponibles y la información del estudio.

## Páginas

- `index.html`: Página de inicio con bienvenida, slider de clases y horarios.
- `nosotros.html`: Historia, misión, visión e instalaciones.
- `clases.html`: Información sobre las clases y los paquetes.
- `contacto.html`: Formulario de contacto y mapa de ubicación.

## Tecnologías utilizadas

- HTML5 y CSS3
- Flexbox y media queries para el diseño responsivo
- JavaScript
- jQuery 
- bxSlider para el slider de clases
- Google Maps mediante un iframe

## Archivos JavaScript

- `studio.js`: Fecha y hora, modo noche, menú móvil y botón para regresar al inicio.
- `slider.js`: Configuración del slider de clases.
- `nosotros.js`: Efectos de jQuery en la página Nosotros.
- `clases.js`: Eventos y manipulación del DOM en la página Clases.
- `contacto.js`: Validación del formulario de contacto.
